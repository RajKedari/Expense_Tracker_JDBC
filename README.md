# 💰 Expense Tracker (JDBC + MySQL)

A simple **Expense Tracker** built using **Core Java** and **JDBC**, designed to manage personal expenses efficiently.

---

## 🚀 Features
- Add, view, update, and delete expenses
- Stores data securely using MySQL database
- Uses JDBC for database connectivity
- Modular, OOP-based design

---

## 🛠️ Tech Stack
- Java (Core)
- JDBC
- MySQL
- IntelliJ IDEA

---

## 🧠 Concepts Used
- Object-Oriented Programming (OOP)
- Exception Handling
- Collections Framework
- CRUD Operations
- JDBC Connectivity
